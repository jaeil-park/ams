# AMS Dell 워런티 조회 확장 프로그램

Dell TechDirect API 키가 나오기 전까지 Dell 워런티 조회를 처리하는 Edge/Chrome 확장 프로그램입니다.
AMS '워런티 조회'에서 **Dell 확장 프로그램 대기**로 쌓인 건을, 사용자가 연 Dell 지원 사이트 탭 안에서 조회해 AMS에 저장합니다.

> TechDirect API 키를 `infra/.env.prod` 의 `DELL_API_CLIENT_ID/SECRET` 에 넣으면 Dell 조회는 백엔드가 바로 처리하므로
> 이 확장 프로그램은 더 이상 필요 없습니다.

## 설치 (Edge 기준, Chrome 도 같음)

1. 이 폴더(`tools/dell-warranty-extension`)를 PC 에 둡니다.
2. 주소창에 `edge://extensions` (Chrome: `chrome://extensions`) 입력
3. 왼쪽 아래 **개발자 모드** 켜기
4. **압축 풀린 확장 로드** → 이 폴더 선택
5. 툴바의 퍼즐 아이콘에서 **AMS Dell 워런티 조회**를 고정

## 사용

1. 확장 프로그램 아이콘 클릭 → AMS 주소(예: `http://192.168.0.22:8070`), AMS 이메일·비밀번호 입력 → **로그인**
   - AMS 주소 접근 권한을 묻는 창이 뜨면 허용합니다.
   - 비밀번호는 저장하지 않고 로그인 토큰만 보관합니다. (토큰 만료 시 다시 로그인)
2. **대기 건 처리**: AMS 의 Dell 대기 건(최대 50건)을 가져와 Dell 사이트에서 조회하고 결과를 AMS 에 저장합니다.
   - Dell 지원 사이트 탭이 없으면 자동으로 하나 엽니다. (`https://www.dell.com/support/contractservices/ko-kr/`)
   - AMS 에 등록된 서버로 요청된 건은 서버 워런티(출처 `DELL_WEB`)까지 자동 저장됩니다.
3. **직접 조회**: AMS 저장 없이 서비스 태그 결과만 보고 엑셀용으로 복사할 수 있습니다.

## 동작 방식과 주의

- 사용자가 버튼을 누를 때만 동작하며, 건마다 1.5초 간격을 둡니다.
- Dell 사이트의 '지원 서비스 상태 확인' 화면이 쓰는 요청을 그 탭 안에서 그대로 실행합니다.
- 'Dell 사이트 응답 403' 이 나오면 Dell 탭을 새로고침(또는 사이트에서 한 번 직접 검색)한 뒤 다시 시도하세요.
- 시작일은 Dell 사이트의 '현재 지원 계약 시작일'입니다. (출하일과 며칠 차이 날 수 있음)
