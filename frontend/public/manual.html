AMS ERP 사용 설명서

이제누리 IT 자산 관리 시스템(AMS: Asset Management System) 이용 가이드입니다. 기준 버전 v1.2.0

시작하기

로그인 및 기본 화면 구성 안내

발급받은 이메일 계정과 비밀번호로 로그인합니다. 로그인 후 좌측 사이드바를 통해 각 메뉴로 이동할 수 있으며, 상단 헤더의 ≡ 버튼으로 사이드바를 접거나 펼칠 수 있습니다.

권한 구분

  • USER — 대시보드, 고객사/프로젝트/서버/파트/납품 관련 조회 및 등록 가능
  • ADMIN — USER 권한에 더해 사용자 관리, 감사 로그 열람, 승인 요청 최종 처리 가능
비밀번호를 잊었거나 계정이 비활성화된 경우 관리자(ADMIN)에게 문의하세요.

사이드바 하단 Family Sites

  • 공식홈페이지 — 이제누리 홈페이지
  • DCIM (고객사 자산관리) — 고객사 통합자산관리 솔루션
  • 사내그룹웨어 — 사내 그룹웨어 (문의 창구)

공통 화면 사용법

모든 목록 화면에서 동일하게 동작하는 기능

페이지 표시 건수

목록 하단 좌측의 표시 건수 선택 상자에서 한 페이지에 몇 건을 볼지 고를 수 있습니다. 10개 / 30개 / 50개 / 100개 / 전체 중에서 선택하며, 변경하면 자동으로 1페이지부터 다시 조회합니다.

엑셀로 옮기거나 전체를 한눈에 훑어봐야 할 때는 전체를 선택하세요. 데이터가 많으면 불러오는 데 시간이 걸릴 수 있습니다.

상태 배지

진행상태·장비상태는 색깔 점이 붙은 배지로 표시됩니다. 색으로 상태를 빠르게 구분할 수 있으며, 같은 색 규칙이 모든 화면에서 동일하게 적용됩니다.

검색과 필터

목록 상단의 검색창과 필터는 함께 적용됩니다. 찾는 데이터가 보이지 않으면 먼저 필터가 걸려 있는지 확인하세요.

대시보드

실시간 자산 및 납품 현황 요약

전체 가용 서버 재고, 진행 상태별 프로젝트 건수, 고객사별 납품 현황, 파트 재고 현황, 최근 입고/장비 장착 이력을 한눈에 확인할 수 있습니다.

KPI 카드 바로가기

상단 4개 카드(가용 재고 / 대기 중 / 진행 중 / 납품 완료)를 클릭하면 해당 상태로 필터가 걸린 상태의 목록 화면으로 바로 이동합니다.

부품(파트) 보유 현황

도넛 차트는 파트를 구분(카테고리) 단위로 묶어 집계합니다. 범례의 (N종)은 그 카테고리에 등록된 품목 종류 수, 우측 숫자는 총 보유 수량입니다. 범례 항목을 클릭하면 해당 카테고리로 검색된 파트재고 화면으로 이동합니다.

구분 값이 비어 있는 파트는 미분류로 묶여 표시됩니다. 파트재고 화면에서 구분을 지정해주면 정상 집계됩니다.

고객사 관리

AMS와 거래하는 고객사 기본정보 관리

고객사 신규 등록 버튼으로 고객사명, 사업자번호, 담당자, 연락처, 상태(활성/비활성)를 입력해 등록합니다. 목록에서 수정 / 삭제로 관리하며, 상태 필터로 활성/비활성 고객사만 조회할 수 있습니다.

고객사 코드는 등록 시 자동으로 부여됩니다(C00001 형식). 직접 입력할 필요가 없습니다.

담당자 관리

한 고객사에 담당자를 여러 명 등록할 수 있습니다. 등록 화면의 + 담당자 추가로 이름·연락처·이메일·직급을 입력해 추가하며, 그중 한 명을 기본 담당자로 지정합니다.

여기에 등록한 담당자는 프로젝트 관리의 담당자 선택 드롭다운에 그대로 나타납니다. 담당자가 퇴사해 프로젝트 담당자를 바꿔야 할 때, 프로젝트 화면에서 고객사에 등록된 담당자 목록 중에서 골라 교체하면 됩니다.

프로젝트 화면의 드롭다운이 비어 있다면 그 고객사에 아직 담당자가 한 명도 등록되지 않은 경우입니다. 고객사 관리에서 먼저 담당자를 추가하거나, 프로젝트 화면에서 바로 신규 담당자를 추가할 수 있습니다.

프로젝트 관리

고객사별 납품 프로젝트(PO) 관리

PO 번호, 프로젝트명, 고객사, 담당자/연락처/이메일, 납품일정, 진행상태(대기 / 진행중 / 완료)를 등록·관리합니다. 행 좌측의 > 를 누르면 그 프로젝트에 묶인 서버·파트 목록이 펼쳐집니다.

진행상태 탭

화면 상단이 진행중 / 대기 / 완료 / 전체 탭으로 나뉘며, 각 탭 옆 숫자는 해당 프로젝트 건수입니다. 화면을 열면 진행중 탭이 기본으로 선택되므로, 완료된 프로젝트에 밀리지 않고 지금 챙겨야 할 건만 바로 보입니다.

탭 숫자는 검색어·고객사 필터를 반영해 함께 바뀌므로, 특정 고객사를 선택하면 그 고객사의 진행중/완료 건수만 표시됩니다.

담당자 지정

고객사를 선택하면 그 고객사에 등록된 담당자 목록이 드롭다운으로 표시됩니다. 목록에서 고르면 연락처·이메일이 자동으로 채워지며, 목록에 없는 새 담당자는 이 화면에서 바로 추가할 수 있습니다.

진행상태 변경 시 납품 상태 자동 연동

프로젝트의 진행상태를 바꾸면, 그 프로젝트에 소속된 서버들의 장비상태가 함께 변경됩니다.

프로젝트 진행상태소속 서버 장비상태
진행중 (IN_PROGRESS)→ 납품예정 (SCHEDULED)
완료 (COMPLETED)→ 납품완료 (DELIVERED)
RMA 상태의 장비는 자동 변경되지 않습니다. 반품/교환은 별도로 관리해야 하는 예외 건이므로, 프로젝트를 완료 처리해도 RMA 장비는 그대로 남습니다. 필요하면 납품목록에서 개별로 상태를 바꿔주세요.
자동으로 변경된 서버 대수는 감사 로그에 함께 기록되므로 나중에 확인할 수 있습니다.

납품목록 (서버)

서버 인벤토리 등록 및 상태 관리

서버 1대씩 등록하는 단건 입고와, 동일 사양의 서버를 여러 대 한 번에 등록하는 동일사양 다건 복사 입고 두 가지 방식을 지원합니다. 시리얼태그(S/N), 장비 모델, 소속 프로젝트, 장비상태를 관리하며, 스캐너 또는 폰 카메라로 바코드를 스캔해 시리얼태그를 자동 입력할 수 있습니다.

입고 / 출고 탭

화면 상단이 탭으로 나뉘어 있고, 각 탭 옆 숫자는 해당 장비 대수입니다. 화면을 열면 입고 (재고) 탭이 기본으로 선택됩니다.

탭포함되는 장비상태의미
입고 (재고)IN_STOCK · RESERVED · SCHEDULED아직 고객사로 나가지 않은 보유 장비
출고 (납품완료)DELIVERED납품이 끝난 장비
RMARMA반품/교환 처리 중인 장비
전체전부상태 구분 없이 모두

입고 탭에서는 우측의 세부 상태 선택으로 재고 / 예약 / 납품예정 중 하나만 따로 볼 수 있습니다. 탭 숫자는 검색어를 넣으면 검색 결과 기준으로 함께 바뀌므로, 탭에 보이는 건수와 실제 목록이 항상 일치합니다.

대시보드의 가용 재고(서버) 카드를 클릭하면 입고 탭의 재고(IN_STOCK) 상태로 필터가 걸린 채 이 화면이 열립니다.

장비상태 값

상태의미
IN_STOCK재고 보유 중
RESERVED특정 프로젝트에 예약됨
SCHEDULED납품 예정
DELIVERED납품 완료
RMA반품/교환 처리 중
프로젝트 관리에서 진행상태를 바꾸면 소속 서버의 장비상태가 자동으로 따라갑니다(RMA 제외). 자세한 내용은 프로젝트 관리를 참고하세요.

PO/프로젝트별 묶어보기

한 프로젝트에 서버를 여러 대 납품하는 경우, 목록 상단의 PO/프로젝트별 묶어보기를 체크하면 PO번호 · 프로젝트명 · N대 헤더로 접히는 그룹 형태로 정리됩니다. 헤더를 클릭하면 접거나 펼칠 수 있고, 대수가 많은 PO가 위로, 미할당(가용재고)은 맨 아래에 표시됩니다.

서버는 S/N·워런티·IP가 장비마다 다르므로 1대 = 1행이 유지되며, 보는 방식만 묶입니다. 그룹화는 현재 페이지에 조회된 목록 기준이므로, 전체를 한 번에 묶어 보려면 하단 표시 건수를 전체로 바꾸세요.

상세 사양 입력

CPU, 메모리, 디스크, NIC, 펌웨어 버전을 함께 기록합니다.

  • 디스크 — 종류가 여러 개인 경우 최대 5개 슬롯까지 각각 사양/수량/RAID를 나눠 입력할 수 있습니다.
  • 추가 파트 — NIC, HBA 등 기본 항목에 없는 부품은 추가 파트 항목으로 자유롭게 늘려 입력합니다.
  • 비고 — 특이사항을 자유롭게 남깁니다.

워런티(보증기간)

목록에서 시리얼태그를 클릭하면 상세 화면이 열리며, 여기서 보증 시작일/종료일을 직접 입력해 저장합니다. 아직 입력하지 않은 장비는 보증 정보 없음으로 표시되며, 이는 오류가 아닙니다.

파트재고

부품(파트) 재고 및 프로젝트 할당 관리

부품 구분(카테고리), 모델명, 파트넘버, 보유 수량, 보관 위치, 할당 프로젝트, 비고를 관리합니다. 검색창에서는 모델명뿐 아니라 구분·파트넘버·보관 위치로도 찾을 수 있습니다.

구분(카테고리)

구분은 드롭다운에서 선택합니다. 목록에 없는 새 카테고리가 필요하면 + 직접 입력을 골라 직접 입력하세요. 한 번 저장하고 나면 그 값이 이후부터 드롭다운 목록에 자동으로 나타나며, 다른 사용자 화면에서도 동일하게 보입니다.

수량 변경 — 입고 추가 / 사용등록

버튼용도입력값
입고 추가재고가 들어와 수량을 늘릴 때늘릴 수량 (예: +5)
사용등록파트를 출고해 수량을 줄일 때출고 수량, 고객사, PO/PR, 사용일자, 사유
두 작업 모두 즉시 반영되지 않습니다. 승인 요청이 접수되어 승인 관리에 대기 건으로 쌓이고, ADMIN이 승인해야 실제 재고에 반영됩니다.

PO/PR 번호는 파트 단품 납품이나 per-call 건을 구분하기 위한 항목으로, 사용등록 화면에서 프로젝트명 또는 PO 번호 일부를 입력하면 자동완성으로 검색됩니다. 선택하면 고객사가 자동으로 채워집니다.

히스토리 및 사용현황

모델명을 클릭하면 해당 파트의 이력 화면이 열립니다. 현재 보유 수량, 보증 상태, 비고에 적어둔 특이사항과 함께, 사용일자·수량·납품 위치·사유가 담긴 출고 이력을 확인할 수 있습니다.

출고 이력에는 승인이 완료된 건만 표시됩니다. 요청했는데 목록에 없다면 아직 승인 대기 중인지 승인 관리에서 확인하세요.

납품이력

납품 완료된 장비의 히스토리 조회

상태가 DELIVERED로 변경된 서버 장비의 납품완료일자, 시리얼태그, 모델명을 시간순으로 조회할 수 있는 읽기 전용 화면입니다.

납품주소

고객사별 납품 거점(배송지) 관리

고객사마다 여러 개의 납품 거점(위치)을 등록해두고, 프로젝트/납품 등록 시 선택해 재사용할 수 있습니다.

승인 관리

수량 변경 등 민감한 변경 요청의 검토·승인

일반 사용자가 요청한 변경 건이 대기 중(PENDING) 상태로 쌓이며, ADMIN이 요청 내용을 검토해 승인 또는 반려 처리합니다. 사이드바 승인 관리 메뉴 옆의 빨간 숫자로 대기 건수를 바로 확인할 수 있습니다.

요청 종류내용승인 시 반영
PART_QTY파트 재고 수량 보정 / 입고 추가보유 수량이 요청한 값으로 변경
PART_USAGE파트 출고(사용) 등록보유 수량 차감 + 사용 이력 기록
상태 필터 기본값은 전체입니다. 대기 중인 건만 보려면 필터를 대기 중으로 바꾸세요. 출고 승인 시점에 재고를 다시 확인하므로, 승인 전에 재고가 부족해졌다면 승인이 거절됩니다.

사용자 관리 ADMIN

시스템 접근 계정 및 권한 관리

계정 생성으로 이메일, 이름, 초기 비밀번호, 권한(USER/ADMIN)을 지정해 계정을 만듭니다. 목록에서 수정(정보/권한 변경), 비활성화(로그인 차단), 삭제(하드 삭제, 복구 불가)를 수행할 수 있습니다.

자기 자신의 계정은 비활성화·권한 변경·삭제할 수 없습니다 (관리자 잠금 방지). 삭제는 되돌릴 수 없으니 신중히 사용하세요.

감사 로그 ADMIN

모든 자산 변경 이력 추적

등록·수정·삭제 등 시스템 내 모든 변경 작업이 자동으로 기록됩니다. 자원 타입(고객사/서버/서버 일괄/프로젝트/파트), 작업 종류, 기간으로 필터링할 수 있으며, 각 로그는 변경 전/후 필드 단위 상세 내역을 함께 보여줍니다.

시스템 로그 ADMIN

API 요청 처리 중 발생한 오류/실패 자동 기록

화면 조작이 뜻대로 되지 않을 때(등록/수정/삭제 실패 등) 원인을 확인할 수 있도록, 서버가 처리 중 만난 오류를 자동으로 기록합니다. 목록 행을 클릭하면 상세 메시지(오류 내용, 발생 위치)를 펼쳐볼 수 있습니다. 기간 필터는 오늘 날짜가 기본값이므로, 과거 이력을 보려면 시작일을 앞으로 당겨 조회하세요.

자주 묻는 질문

Q. 로그인 후 자꾸 로그아웃돼요.

세션 자동 갱신이 동작하지 않던 문제가 v1.1.0에서 수정되었습니다. 그래도 반복된다면 브라우저 저장공간(로컬 스토리지)이 차단된 경우일 수 있으니, 시크릿 모드가 아닌 일반 브라우저 창에서 다시 로그인해 보세요.

Q. 목록에서 방금 등록한 데이터가 안 보여요.

목록 상단의 상태/기간 필터가 적용되어 있는지 확인하세요. 초기화 버튼으로 필터를 해제하면 전체 데이터를 볼 수 있습니다. 대시보드 카드를 눌러 이동한 경우에는 그 상태로 필터가 걸려 있습니다.

Q. 파트 수량을 바꿨는데 목록에 그대로예요.

입고 추가와 사용등록은 ADMIN 승인 후에 반영됩니다. 승인 관리 화면에서 요청이 대기 중인지 확인하세요.

Q. 한 페이지에 더 많이 보고 싶어요.

목록 하단 좌측의 표시 건수를 50개 / 100개 / 전체로 바꾸면 됩니다.

Q. 삭제/비활성화 버튼을 눌렀는데 반응이 없어요.

브라우저의 확인 팝업(정말 삭제하시겠습니까?)이 떴는지 확인하세요. 팝업 차단 확장 프로그램을 사용 중이라면 이 사이트에 대해 팝업을 허용해주세요.

Q. 문의는 어디로 하나요?

사이드바 하단 Family Sites의 사내그룹웨어를 통해 IT 담당자에게 문의하시기 바랍니다.
